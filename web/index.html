A SMALL GUIDE
连接与安全
这几个端口分别在哪里？
反向转发的入口位于远端服务器，目标服务位于 本机可访问的网络。服务器程序访问自己的入口端口，SSH 把请求带回本机。跳板机负责中转，不会自动获得代理入口。
远端入口 → SSH 隧道 → 本机上的目标服务
为什么运行中还需要检测？
SSH 进程运行，不代表本机代理已启动，也不代表目标网站可达。“检测链路”会通过指定入口进行实际请求。Windows 检测会建立新的 SSH 会话，需要服务器及跳板机都能通过密钥或 ssh-agent 登录。
密码和主机指纹
Windows 版使用密钥或 ssh-agent，不提供密码弹窗。首次连接请先在 PowerShell 中正常 SSH 登录，核对主机指纹，再用 BatchMode=yes 验证免交互登录。README 包含逐步配置说明。
Windows 登录自启动
在 PowerShell 中运行 py -3 main.py --install-service --open，注册当前用户的任务计划。该任务启动网页后台；需要自动恢复的通道，请在配置中启用自动重连。停止计划任务可能同时停止其创建的 SSH 进程。
回环地址不是账户隔离
127.0.0.1 避免把入口直接暴露到其他机器，但服务器上的其他用户和进程通常也能使用它。模型接口仍应配置访问密钥。共享电脑或服务器上，请按实际需要限制代理的访问目标。
关闭页面会怎样？
关闭浏览器不会停止后台或 SSH 隧道。本机休眠、断网，或关闭其依赖的代理服务，则可能中断连接。管理器不会修改系统代理、路由或 SSH 服务端设置。
